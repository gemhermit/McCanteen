## 规范

1. **设计系统 v2**（2026-10-15 起）：
   - 背景：米白垂直渐变 `#FFFBF2 → #FFF1DB` + 细点阵纹理（72px 间距，透明度 12）；
   - 头部：红渐变横幅 `#E54032 → #BA1F17`（208px）+ 黄色收口条（8px）+ 标题深色投影；
   - 深度：所有内容卡带柔和投影（GaussianBlur，透明度 45-60，偏移 6px）；
   - 徽章：渐变药丸（等级/常驻单品）、渐变圆章（金银铜名次）、金色渐变成就 chip；
   - 吉祥物：汉堡分层渐变合成（下层面包/肉饼/芝士/生菜/上层面包，每层独立渐变 + 卡通描边），
     带弧线光泽、杏仁芝麻、烤痕、芝士垂滴，以及表情（眉毛/眼睛高光/腮红/微笑）——卡片的灵魂
2. **配色**：麦当劳红 `#DA291C` / 黄 `#FFC72C` / 米白系渐变（视觉致敬，非官方素材）。
3. **字体**：按候选列表探测（微软雅黑 → 黑体 → PingFang → Noto → 文泉驿），全部缺失时明确报错，**不用默认位图字体硬渲染**。
4. **防溢出**：所有文本经 `wrap_text` 换行 + `fit_font` 缩字号；中文按字符贪心断行。
5. **诚实性**：卡片页脚必须包含「演示数据仅供参考」或「真实数据来自麦当劳 MCP」字样与「非麦当劳官方作品」声明。
6. **确定性**：同一输入 → 同一张卡（无随机抖动），方便回归比对。
