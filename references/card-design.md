## 规范

1. **配色**：麦当劳红 `#DA291C` / 黄 `#FFC72C` / 米白 `#FFF8EB`（视觉致敬，非官方素材）。
2. **字体**：按候选列表探测（微软雅黑 → 黑体 → PingFang → Noto → 文泉驿），全部缺失时明确报错，**不用默认位图字体硬渲染**。
3. **防溢出**：所有文本经 `wrap_text` 换行 + `fit_font` 缩字号；中文按字符贪心断行。
4. **诚实性**：卡片页脚必须包含「演示数据仅供参考」或「真实数据来自麦当劳 MCP」字样与「非麦当劳官方作品」声明。
5. **确定性**：同一输入 → 同一张卡（无随机抖动），方便回归比对。
