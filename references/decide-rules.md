# 决断规则（decide-rules）

打分逻辑的单一事实来源。权重调整必须同步更新本文件与 `src/mccanteen/decide.py`。

## 时段定义（麦当劳的一天）

| 时段 | 键 | 时间窗 | 台词 |
|---|---|---|---|
| 早餐 | `breakfast` | 05:00–10:29 | Morning call！麦满分和热豆浆在等你 |
| 午餐 | `lunch` | 10:30–13:59 | 正餐时间，填饱肚子才有力气搬砖 |
| 下午茶 | `tea` | 14:00–16:59 | 三点几啦，饮茶先啦！ |
| 晚餐 | `dinner` | 17:00–20:59 | 收工前的仪式感，整点好的 |
| 夜宵 | `latenight` | 21:00–04:59（跨午夜） | 加班再晚，也要喂饱自己 |

时段决定两件事：① 哪些餐品可售（硬过滤）；② 食堂的语气。

## 打分权重

| 因素 | 分值 | 说明 |
|---|---:|---|
| 券适用 | +25 | 该餐品能用上手里的券 |
| 券 48h 内过期 | +15 | 「用了就是止损」——损失厌恶加权 |
| 7 天内吃过 | −20 | 反重复，除非 `--allow-repeat` |
| 从没点过 | +5 | 舒适区挑战 |
| 明确点名品类（渴/饮料） | +50 | **明确诉求优先于优惠引导** |
| 明确点名咖啡 | +50 | 同上 |
| 低卡（≤450 kcal） | +12 | 处境含健身/减脂等关键词 |
| 高蛋白（≥15 g） | +8 | 同上 |
| 热量管够（≥400 kcal 或套餐） | +8 | 处境含累/加班/emo 等关键词 |
| 适合分享（套餐/小食/甜品） | +10 | 处境含请客/团建等关键词 |

排序：`(-score, 价格升序)`，取前 3。摇一摇模式从得分前 5 中真随机取 1。

## 处境关键词 → 餐品方向

| 关键词 | 方向 |
|---|---|
| 健身 / 减脂 / 减肥 / 低卡 / 控卡 / 轻食 / 沙拉 | light |
| 累 / 加班 / 熬夜 / emo / 低落 / 烦躁 / 垮 / 心累 | comfort |
| 渴 / 热 / 喝水 / 饮料 / 可乐 | drink |
| 请客 / 聚餐 / 团建 / 分享 / 聚会 | share |
| 困 / 提神 / 咖啡 / 犯困 | coffee |

## 硬约束

1. **时段**：只推当前时段可售餐品。
2. **预算**：`--budget` 内只推预算内餐品；预算内无解时自动放宽，并在结论中如实说明（`budget_relaxed`）。
3. **价格**：全部来自 MCP 真实计价或 fixtures 演示数据，引擎从不估算价格。

## 设计立场

- 决断优先于优化：用户要的是「现在就决定」，不是「再比三家」。
- 优惠是加分项，不是决定项：明确说「想喝咖啡」时，不会因为一张甜筒券过期就改推甜筒。
- 反重复是默认开启的：食堂的价值就是帮你走出「永远板烧鸡腿堡」的循环。
